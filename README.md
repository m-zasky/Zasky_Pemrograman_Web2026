# 🌐 Pemrograman Web 2026 - Kumpulan Praktikum & Proyek

Repositori resmi ini didedikasikan untuk menyimpan seluruh hasil tugas, praktikum, dan pengembangan proyek dari **Sekumpulan Jobsheet** dalam mata kuliah **Pemrograman Web**.

---

## 🗂️ Struktur Direktori Repositori

Repositori ini disusun secara modular berdasarkan modul pembelajaran (*jobsheet*):

- **`jobsheet-01` s.d. `jobsheet-08`**: Dasar-dasar pengembangan web, perancangan struktur HTML/CSS, hingga pengenalan logika pemrograman server-side dan basis data.
- **`jobsheet-09`**: Implementasi sistem CRUD terpadu (Modul Alat & Penyewa), fitur pencarian multi-kolom (*search*), *pagination*, validasi data, hingga penanganan pesan kilat (*flash messages*).
- **`LAPORAN`**: Kumpulan dokumen laporan resmi dari setiap rangkaian praktikum.

---

## 🛠️ Stack Teknologi
* **Bahasa Pemrograman:** PHP (PDO - *PHP Data Objects*)
* **Basis Data:** PostgreSQL
* **Front-end:** HTML5, CSS3, JavaScript
* **Kontrol Versi:** Git & GitHub

---

## 🚀 Fitur Utama Sistem (Proyek Akhir)
1. **Manajemen Data Terpadu:** Pengelolaan entitas data secara lengkap dengan pola struktur file yang konsisten (`list.php`, `tambah.php`, `edit.php`, `hapus.php`).
2. **Keamanan & Validasi:** Penerapan *prepared statements* dengan PDO untuk mencegah *SQL Injection*.
3. **Pengalaman Pengguna:** Dilengkapi dengan fitur pencarian data lanjutan (*multi-column search*), pembagian halaman (*pagination*), serta konfirmasi interaktif berbasis JavaScript.
